# Skillo AI — v1.1 Architecture Snapshot

> **Status**: Frozen reference document. Do not modify this file when v2 development begins.
> This represents the exact, honest architecture as of the v1.1.0 release gate.

---

## Overview

Skillo AI is a personalized career learning path assistant. It takes a learner's current skills and a free-text career goal, identifies skill gaps against a curated taxonomy, and generates a prerequisite-ordered learning roadmap. It then adapts the roadmap in real time based on quiz assessment results.

The system has **no general-purpose AI component** at its core. The recommendation engine is entirely graph-based and vector-based with deterministic outputs. The only probabilistic/generative component (Gemini LLM) is a non-critical, optional enhancement for human-readable explanations only.

## Core Pipeline (Sequential)

```
Learner
  │
  ├── Current Skills (manually selected from taxonomy)
  └── Career Goal (free-text natural language sentence)
           │
           ▼
  ┌─────────────────────────────────┐
  │       Goal Parsing Engine       │
  │                                 │
  │  1. Character n-gram TF-IDF     │
  │     vectorization (char_wb,     │
  │     ngrams 3–5, sublinear_tf)   │
  │  2. Cosine similarity vs.       │
  │     role descriptions + aliases │
  │  3. Alias keyword boost         │
  │  4. Score clamped to [0.0, 1.0] │
  │  5. Gemini SDK fallback         │
  │     (optional, if API key set)  │
  └──────────────┬──────────────────┘
                 │
                 ▼
            Career Role
         (from 6-role taxonomy)
                 │
                 ▼
  ┌─────────────────────────────────┐
  │      Skill Gap Analyzer         │
  │                                 │
  │  1. Load required skills for    │
  │     target role                 │
  │  2. Vectorize each required     │
  │     skill + each current skill  │
  │     (same TF-IDF vectorizer,    │
  │     fitted on full taxonomy)    │
  │  3. Pairwise cosine similarity  │
  │  4. Threshold τ = 0.60          │
  │     MATCH  → already mastered   │
  │     GAP    → needs to be learned│
  │  5. Fallback: Jaccard token     │
  │     similarity if vectorizer    │
  │     unavailable                 │
  └──────────────┬──────────────────┘
                 │
                 ▼
    Missing Skills (ordered list)
                 │
                 ▼
  ┌─────────────────────────────────┐
  │  Prerequisite Graph Generator   │
  │                                 │
  │  1. Load 29 directed edges      │
  │     from seed_prerequisites.json│
  │  2. Build NetworkX DiGraph      │
  │  3. Add missing skills as nodes │
  │  4. Compute transitive closure  │
  │     (prerequisite expansion)    │
  │  5. Topological sort            │
  │  6. Raises error if DAG cycle   │
  │     detected (0 cycles in       │
  │     current taxonomy)           │
  └──────────────┬──────────────────┘
                 │
                 ▼
         Learning Roadmap
    (ordered list of RoadmapStep)
                 │
                 ▼
  ┌─────────────────────────────────┐
  │   Resource Assignment           │
  │                                 │
  │  For each step:                 │
  │  1. Look up skill_id in         │
  │     seed_resources.json         │
  │  2. Select first non-remedial   │
  │     resource for primary step   │
  │  3. Assign remedial resource    │
  │     for potential refresher use │
  └──────────────┬──────────────────┘
                 │
                 ▼
  ┌─────────────────────────────────┐
  │   Explainable AI (XAI)          │
  │                                 │
  │  For each step, inspect graph:  │
  │  1. Upstream: what prerequisites│
  │     does this build on?         │
  │  2. Downstream: what does this  │
  │     skill unlock next?          │
  │  3. Template-based synthesis    │
  │     → deterministic explanation │
  │  4. Gemini LLM enrichment       │
  │     (optional, if API key set)  │
  └──────────────┬──────────────────┘
                 │
                 ▼
         Roadmap Displayed
         (Next.js Dashboard)
                 │
                 ▼
  ┌─────────────────────────────────┐
  │   Adaptive Feedback Loop        │
  │                                 │
  │  On quiz submission:            │
  │                                 │
  │  Score < 50%:                   │
  │    → Insert remedial step at    │
  │      current_index + 1          │
  │                                 │
  │  Score ≥ 90%:                   │
  │    → Flag downstream dependent  │
  │      steps as "skippable"       │
  │                                 │
  │  Score 50–89%:                  │
  │    → Mark step as "completed"   │
  │      and advance pointer        │
  │                                 │
  │  All cases:                     │
  │    → Persist updated roadmap    │
  │      to database                │
  └─────────────────────────────────┘
```

## LLM Boundary (Separate, Non-Critical Path)

```
Gemini SDK (google.genai.Client)
  │
  ├── Goal Parsing fallback
  │   (only if primary TF-IDF parse
  │    has very low confidence or
  │    GEMINI_API_KEY is set)
  │
  └── XAI Explanation enrichment
      (optional, adds natural language
       context to template explanations)
```

**The core recommendation pipeline does not depend on the LLM.** If no API key is set, all core functionality works fully through deterministic TF-IDF matching and graph traversal.

## Technology Stack

| Layer | Technology | Purpose |
|---|---|---|
| **Web Framework** | FastAPI (Python) | REST API server, route handling, Pydantic schemas |
| **ML: Goal Parsing** | scikit-learn TF-IDF (char n-gram) | Convert goal text and role descriptions to vectors |
| **ML: Gap Analysis** | scikit-learn TF-IDF + cosine similarity | Pairwise skill matching against role requirements |
| **Graph Engine** | NetworkX DiGraph | Build DAG, compute transitive prerequisite closure, topological sort |
| **Optional LLM** | Google Gemini SDK | XAI enrichment and goal parse fallback |
| **Frontend** | Next.js 14 (React), Tailwind CSS | Onboarding wizard, roadmap timeline, quiz UI |
| **Storage (Primary)** | Google Cloud Firestore | Cloud document database |
| **Storage (Fallback)** | Local JSON file (`db_storage.json`) | Zero-config offline mode |
| **Security** | bcrypt | Password hashing with adaptive work factor |
| **Auth** | Bearer token | Session ownership verification |

## Data Taxonomy (Frozen at v1.1)

| Collection | Count | Description |
|---|---|---|
| `skills` | **36** | Engineering competencies with name, category, description |
| `roles` | **6** | Career roles with required skill lists |
| `prerequisites` | **29** | Directed dependency edges between skills |
| `resources` | **49** | Curated learning resources per skill (primary + remedial) |

**The 6 supported roles:**
- Frontend Developer
- Backend Developer
- Full Stack Developer
- Machine Learning Engineer
- AI Engineer
- DevOps Engineer

## Database Collections Schema

```
learners/
  learner_id: str
  name: str
  current_skills: List[str]       # skill names (self-reported)
  target_role_id: str
```

## API Surface

| Method | Endpoint | Purpose |
|---|---|---|
| `POST` | `/api/v1/auth/signup` | Register a new user + learner profile |
| `POST` | `/api/v1/auth/login` | Authenticate and receive session token |
| `GET` | `/api/v1/taxonomy` | Fetch all skills and roles |
| `POST` | `/api/v1/goal` | Parse free-text career goal → role + target skills |
| `POST` | `/api/v1/profile` | Save or update learner profile |
| `POST` | `/api/v1/recommend` | Generate (or retrieve cached) roadmap |
| `GET` | `/api/v1/roadmap/{learner_id}` | Fetch active roadmap (404 if none) |
| `POST` | `/api/v1/feedback` | Submit quiz result, trigger roadmap adaptation |
| `GET` | `/api/v1/explain/{learner_id}/{step_id}` | Fetch XAI explanation for a step |
| `GET` | `/api/v1/history/{learner_id}` | List all roadmap history entries |
| `POST` | `/api/v1/history/activate` | Switch active roadmap to a historical one |
| `DELETE` | `/api/v1/history/{learner_id}/{history_id}` | Permanently delete a history entry |

## Known Invariants (All Verified at v1.1)

- Cosine similarity scores are strictly bounded to `[0.0, 1.0]`.
- The prerequisite graph has 0 cycles (`nx.is_directed_acyclic_graph = True`).
- Every prerequisite edge references valid skill IDs (no orphans).
- Every resource references a valid skill ID (no orphans).
- Deleting a roadmap permanently removes it from all storage — no ghost resurrection.
- The core recommendation pipeline produces identical output for identical inputs (deterministic).
- Passwords are stored exclusively as bcrypt hashes (never plaintext or SHA).
- The LLM is never in the critical recommendation path — 100% of core functionality works without it.
